# 電球の口金・色温度スマート判定メーカー

家中の切れた電球をスマホで撮影するだけで、正しい口金サイズと明るさを一発で特定し買い間違いを防ぐツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/household-bulb-socket-finder/）。
2. 画面の指示に従って操作します。
